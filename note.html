法規 1｜銀行業務相關規範（每屆約 4 題；高頻 23 題）

  • ⭐⭐4屆｜依主管機關規定，金融機構不得與客戶概括授權將活期存款轉入下列何者存款帳戶？ → 同一金融機構之支票存款（49-38、44-36、41-36、37-36）
  • ⭐⭐4屆｜有關活期存款依約定方式提取存款之規範，下列敘述何者正確？ → 金融機構依約定辦理轉帳後，應寄發對帳通知（42-36、38-36、33-36、29-32）
  • ⭐3屆｜依銀行法第七條有關活期存款依約定方式提取存款之規範規定，金融機構得與客戶約定之轉帳方式，下列敘述何者錯誤？ ❌錯的是 不得將活期存款轉入其他金融機構之活期存款帳戶（47-37、39-35、36-35）
  • ⭐3屆｜凡提領外匯存款兌換為新臺幣，金額達新臺幣五十萬元以上者，應請客戶填寫下列何種書表？ → 外匯收支或交易申報書（46-28、37-25、33-25）
  • ⭐3屆｜依銀行法規定，銀行對於無自用住宅者購買自用住宅之放款，最長期限不得超過多久？ → 無期限限制（45-3、34-3、32-1）
  • ⭐3屆｜金融機構遇有存戶未及時領回存摺，於立即設簿登記後，應採取之處理方式，下列何者不恰當？ ❌錯的是 由經辦人員妥慎保管（40-36、36-36、29-33）
  • ⭐2屆｜依銀行法規定，因自用住宅放款及消費性放款而徵取之保證人，其保證契約自成立之日起，有效期間不得逾多久？（但經保證人書面同意者，不在此限） → 十五年（48-4、37-1）
  • ⭐2屆｜依「銀行辦理衍生性金融商品業務內部作業制度及程序管理辦法」規定，有關商品部位評價頻率，下列敘述何者錯誤？ ❌錯的是 銀行本身業務之避險性交易，至少每週評估一次（46-29、42-25）
  • ⭐2屆｜依「信託業營運範圍受益權轉讓限制風險揭露及行銷訂約管理辦法」規定，兼營信託業務之銀行申請辦理本法第 17 條各款附屬業務，其應檢附之書件，下列何者非屬之？ ❌錯的是 附屬業務契約範本（45-50、26-35）
  • ⭐2屆｜有關金融機構受理開戶，雙重身分證明文件之查核，下列敘述何者正確？ → 個人戶及非個人戶均須查核（45-36、32-36）
  • ⭐2屆｜依「銀行辦理衍生性金融商品業務內部作業制度及程序管理辦法」規定，關於衍生性金融商品部位之評價頻率，銀行應依照部位性質分別訂定；其為交易部位者，應以即時或每日市價評估為原則；其為銀行本身業務需要辦理之避險性交易者，至少多久評估一次？ → 每月（44-26、40-27）
  • ⭐2屆｜依銀行法規定，銀行對下列何種放款不受三十年期限之限制？ → 無自用住宅者購買自用住宅放款（43-4、29-1）
  • ⭐2屆｜銀行法第 32 條所稱之消費者貸款授信限額，其中每一消費者信用卡循環信用金額之計算，下列何者正確？ → 以信用卡循環信用餘額計算，由銀行在不超過新臺幣一百萬元範圍內自行控管額度（43-49、30-48）
  • ⭐2屆｜金融機構遇有存戶未及時領回存摺時，下列措施何者錯誤？ ❌錯的是 予以銷燬（43-35、42-35）
  • ⭐2屆｜依銀行法規定，銀行對購買或建造住宅或企業用建築，得辦理中、長期放款，除對於無自用住宅者購買自用住宅之放款外，其最長期限不得超過多少年？ → 三十年（41-2、38-2）
  • ⭐2屆｜金融機構為落實於客戶開戶時確認客戶身分，可利用下列何單位之查詢系統，以確定該客戶身分證是否遺失被竊？ → 內政部（38-44、29-39）
  • ⭐2屆｜下列何者非屬銀行法第 32 條所稱消費者貸款之範圍？ ❌錯的是 定期存款質借（38-48、31-48）
  • ⭐2屆｜兼營信託業務之銀行依規定得逕行開辦之新種信託商品，主管機關得令其停止或暫停辦理之情事，下列敘述何者錯誤？ ❌錯的是 於開辦後 15 日內報主管機關備查（38-50、31-50）
  • ⭐2屆｜依主管機關規定，有關客戶申請變更銀行存、放款業務對帳單寄送之方式，下列敘述何者正確？ → 以書面、電話指示或網路銀行方式申請皆可（37-44、34-44）
  • ⭐2屆｜對於客戶未及時領回存摺應即設簿控管，並列入內部稽核項目內，定期查核其與電腦檔案資料是否相符，下列何者非其比對項目？ ❌錯的是 存款密碼（34-35、26-45）
  • ⭐2屆｜金融機構受理開戶，非個人戶部分，依規定除應徵取登記證照外，應徵取下列何者，始可辦理？ A.董事會議紀錄 B.公司章程 C.財務報表 D.股東名冊 → A、B、C（34-36、31-35）
  • ⭐2屆｜依銀行法規定，銀行對於客戶之存款、放款或匯款等有關資料，如符合「對同一客戶逾期債權已轉銷呆帳者，累計轉銷呆帳金額超過新臺幣多少萬元，或貸放後半年內發生逾期累計轉銷呆帳金額達新臺幣多少萬元以上，其轉銷呆帳資料」條件，銀行保密義務得依法予以免除？ → 5,000 萬元；3,000 萬元（33-1、29-2）
  • ⭐2屆｜依「外匯收支或交易申報辦法」規定，申報義務人如發現銀行業掣發之交易憑證內容有與事實不符者，應自銀行業掣發之日起多少個營業日內申請更正？ → 7 日（29-26、26-19）
